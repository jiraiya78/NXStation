NXstationB v1.0: Batocera EmulationStation on Switch

August 28, 2026 · v1.0

Download NXStationB.nro View on GitHub

NXstationB v1.0 is the first public release of Batocera EmulationStation as a Nintendo Switch NRO. Recommended if you want the real Batocera UI, themes, and scraper on Switch alongside NXStation.

Download: github.com/jiraiya78/NXStationB/releases · Wiki: nxstation.com/nxstationb/wiki.html

Highlights

  • Full Batocera ES frontend on Switch (systems, gamelists, scraper, screensaver, themes)
  • Stock RetroArch Switch cores; optional standalone NROs (Tico, etc.) via Emulator and Cores
  • ScreenScraper only (developer API included; set your website login in settings)
  • Bundled themes: Simple_Life (default), es-theme-minimal, es-theme-simple
  • Restores last system + game after a session; fast boot skips extra ROM scanning
  • If NXStation is installed, playtime is written to NXStation analytics

Install

  1. Copy NXStationB.nro to sdmc:/switch/nxstationb/NXStationB.nro
  2. Hold R on an installed game → hbmenu → NXstationB
  3. ROMs in sdmc:/roms/{system}/
  4. Cores in sdmc:/retroarch/cores/

Notes

  • Album / applet mode does not have enough RAM
  • Stock cores on newer firmware usually return to Home; reopen the NRO to resume the last game
  • On firmware 22.5+, Rax cores (recompiled libretro cores) fix crash-on-exit issues; see the FAQ
  • Batocera ES is GPL; Switch port sources will be released in due time
