NXstationB handbook

Paths, launch, scraper, cores, and how this sits next to NXStation.

Install paths

sdmc:/switch/nxstationb/NXStationB.nro is the app binary.

sdmc:/switch/nxstationb/ holds es_systems.cfg, themes, logs, user_cores.json, and navigation_state.txt.

sdmc:/roms/{system}/ for ROMs (shared with NXStation).

sdmc:/retroarch/cores/*.nro for libretro and standalone cores.

Download: GitHub Releases

Title Override

Hold R on any installed title, open hbmenu, launch NXstationB. Album / applet mode will fail or crash on heavier cores.

Scraper

Scrape from = ScreenScraper only. Set website username/password under Scraper → accounts.

Cores

Main menu → Emulator and Cores → system → pick any .nro. RESET restores the es_systems.cfg default. Overrides save to user_cores.json and, if NXStation is installed, also to NXStation’s settings/user_cores.json.

Rax cores (firmware 22.5+)

Rax cores are recompiled RetroArch libretro cores that fix crash-on-exit behavior on Nintendo Switch firmware 22.5 and newer. Stock cores may still play games, but closing a title often returns you to the Home Menu instead of NXstationB.

Rax builds are optional and will be published separately when ready. Until then, reopen NXstationB with Title Override to resume your last game.

Playtime

If sdmc:/switch/NXStation exists, play sessions are appended to data/playtime_nxstation.json. Open NXStation later to see analytics.

Return from a game

Stock cores usually exit to Home. Re-open NXstationB (Title Override). The last system and game are restored from navigation_state.txt with a fast boot (no extra ROM scan).
