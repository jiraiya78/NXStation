NXStation v0.2.2 — Manual viewer polish, Y-menu Game Manual

August 12, 2026 · v0.2.2

GitHub Releases

Documented here ahead of the GitHub release — check GitHub Releases for the downloadable NRO when it ships.

Update v0.2.2 is the recommended build if you are on v0.2.1 or earlier. It polishes the in-app PDF manual viewer and adds a Game Manual entry to the game-list Y menu when a manual exists.

Website: https://nxstation.com Wiki: https://nxstation.com/wiki.html Blog: https://nxstation.com/blog.html Downloads: https://github.com/jiraiya78/NXStation/releases Discussion: GBATemp / GitHub Issues

Highlights

  • Y menu → ◆ Game Manual — top entry when metadata or manuals/{stem}-manual.pdf exists; opens the viewer directly (toast if the file is missing)
  • Manual viewer controls — D-pad / L·R pages; right stick up/down zoom (docked-friendly); left stick pan when zoomed
  • First page fix — cover no longer shows as a blank square until you change pages
  • Fullscreen overlay fix — game list is not navigable or highlighted under the manual viewer; smoother return when closing

Added

  • Y menu → Game Manual when a manual is recorded for the focused game

Changed

  • Manual viewer page navigation: D-pad left/right and L/R only (analog stick nav no longer flips pages)
  • Manual viewer zoom/pan: right stick zoom, left stick pan

Fixed

  • Manual viewer first-page render (texture upload deferred until layout size is valid)
  • Manual viewer blocks game-list focus/selection underneath; deferred highlight restore on close

Notes after upgrading

  • Manuals still open from Y → Menu → Show Metadata → Manual as before
  • Scrape Manual in the scrape menu (off by default) to download PDFs to roms/{systemId}/manuals/
  • Settings → Check for Updates works from v0.1.8+ if you already have a build with the updater

Requirements

  • Modded Switch (e.g. Atmosphere) with homebrew enabled
  • Title Override is required — hold R while launching any game, open the Homebrew Menu, then start NXStation
  • RetroArch for Switch at sdmc:/switch/retroarch_switch.nro
  • RetroArch cores under sdmc:/retroarch/cores/ (or standalone cores in NXStation/cores/)
  • ROMs under sdmc:/roms/ (or your custom ROMs path in Settings)

Installation

  1. Download NXStation.nro from this release (or Settings → Check for Updates from v0.1.8+).
  2. Copy to sdmc:/switch/NXStation/NXStation.nro
  3. Launch via Title Override (hold R → Homebrew Menu → NXStation).

Upgrading keeps your existing settings/ and data/ on SD.

Thank you to everyone who tests, reports issues, and keeps the homebrew scene going.
