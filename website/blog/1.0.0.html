NXStation v1.0.0 — Theme refresh, list browser, zoom transitions

August 28, 2026 · v1.0.0

Download NXStation.nroView on GitHub

Update v1.0.0 is the recommended build if you are on v0.3.0 or earlier. It delivers a major theme and UI refresh: a list-style system browser, Zoom/Crossfade carousel transitions, theme background music, refreshed system wallpapers, and much better carousel text readability on bright or dark art.

Website: https://nxstation.com Wiki: https://nxstation.com/wiki.html Blog: https://nxstation.com/blog/1.0.0.html Downloads: https://github.com/jiraiya78/NXStation/releases Discussion: GBATemp / GitHub Issues

Highlights

  • List-style system browser — game-list layout with per-system art, descriptions, and smooth scrolling (enable in Settings or per theme)
  • 18 light/dark themes with updated system carousel backgrounds
  • Carousel transitions — Fade, Slide, Crossfade, Zoom (new default), or None
  • Theme music — drop bgm.mp3 in your theme folder (data/theme/{name}/); sample track bundled
  • Theme SFX — optional custom navigation sounds per theme
  • Carousel readability — halo text + bottom gradient so titles stay readable on any wallpaper
  • Video preview delay — 1–6 second hover delay in Settings
  • Screensaver — default dark/light backdrop images when a theme has no custom screensaver.jpg

Added

  • System list browser with {systemId}-list.jpg art and system_descriptions.json blurbs
  • Crossfade and Zoom preview transitions (system carousel + list preview card)
  • Theme BGM player (MP3/OGG/WAV) with volume control in Settings
  • Configurable video hover delay (1–6 s)
  • Bundled screensaver backdrops: screensaver.jpg / screensaver-light.jpg
  • HaloLabel + gradient overlay on carousel titles

Changed

  • Refreshed default system backgrounds for all bundled systems
  • System list shares the List Scrollbar setting with the game list
  • Default carousel transition is Zoom

Fixed

  • System list selection highlight and row separators after theme changes
  • Smooth list scrolling and wrap navigation in the system browser
  • Theme BGM discovery and playback on SD (file: paths, decode thread stack)

Credits

  • Sample theme music (bgm.mp3) by Vlad Krotov from Pixabay

Theme assets (optional)

Place files under sdmc:/switch/NXStation/data/theme/{ThemeName}/:

| File | Purpose | |------|---------| | bgm.mp3 / music.mp3 | Looping background music | | sfx/nav.wav, confirm.wav, … | Custom UI sounds | | screensaver.jpg | Screensaver backdrop (overrides bundled default) | | screensaver-light.jpg | Light-theme screensaver | | {systemId}-list.jpg | List-browser preview art | | backgrounds/{systemId}.jpg | Carousel wallpaper |

Bundled sample BGM is also copied to sdmc:/switch/NXStation/sample/bgm.mp3 on first launch.

Requirements

  • Modded Switch (e.g. Atmosphere) with homebrew enabled
  • Title Override is required — hold R while launching any game, open the Homebrew Menu, then start NXStation
  • RetroArch for Switch at sdmc:/switch/retroarch_switch.nro
  • RetroArch cores under sdmc:/retroarch/cores/ (or standalone cores in NXStation/cores/)
  • ROMs under sdmc:/roms/ (or your custom ROMs path in Settings)

Installation

  1. Download NXStation.nro from this release (or Settings → Check for Updates from v0.1.8+).
  2. Copy to sdmc:/switch/NXStation/NXStation.nro
  3. Launch via Title Override (hold R → Homebrew Menu → NXStation).

Upgrading keeps your existing settings/ and data/ on SD.

Thank you to everyone who tests, reports issues, and keeps the homebrew scene going.
