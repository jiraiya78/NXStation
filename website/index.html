Objective

Get started

Quick Setup Guide

Four steps from download to your library on Switch.

  1. 01

    Download the latest .nro

    Grab the release from GitHub and verify the version matches your Atmosphere build.

  2. 02

    Place it on your SD card

    Copy to /switch/NXStation/ on your SD card (alongside config as needed).

  3. 03

    Boot via Title Override required

    Title Override is compulsory. Hold R on a game icon and launch NXStation from there. Do not use the standard Homebrew Menu — the app needs full RAM access to run properly.

  4. 04

    Add your ROMs

    On the SD card root, create a roms folder with one subfolder per system (ES-DE style). Example:

    roms/
├── nes/
│   └── platformer.nes
├── snes/
│   └── adventure.sfc
└── gba/
    └── rpg-title.gba

    See How do I add my games? in the FAQ for folder layout, media, and gamelist.xml details.
