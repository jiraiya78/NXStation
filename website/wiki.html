Title Override vs. Applet Mode

Always launch NXStation via Title Override — hold R while opening any retail Switch game, then pick NXStation from the menu. This gives the app full RAM access for smooth video previews, PDF manuals, and media loading.

Do not launch from the Gallery / Album applet (Applet Mode). Applet Mode limits available memory and can cause previews to lag, fail to load, or crash.

Installation & Updating

In-app updates

  1. Open NXStation (Title Override).
  2. Press + to open Settings.
  3. Choose Check for Updates.
  4. Follow the prompts to download and install the latest release automatically.

Manual installation

  1. Download NXStation.nro from GitHub Releases.
  2. Copy it to sdmc:/switch/NXStation/NXStation.nro on your SD card.
  3. Keep or update settings/roms_config.json in the same folder if you customize systems.

Supported Systems

NXStation ships with 28 systems in the default roms_config.json, covering Atari, Nintendo, Sega, arcade, Sony, and PC Engine platforms:

  • atari2600, atari5200, atari7800, atarilynx, atarijaguar, atarist
  • nes, snes, n64, gb, gbc, gba, nds, 3ds, gc, wii
  • megadrive, mastersystem, gamegear, saturn, dreamcast
  • cps1, cps2, neogeo, arcade
  • psx, psp, pce

You can add more systems by editing roms_config.json when a matching RetroArch core exists.

PlayStation 2 is not supported. PS2 emulation is not practical on Nintendo Switch hardware with current libretro cores. Do not expect a PS2 folder in the default config — focus on PS1 (psx) and PSP (psp) instead.
GameCube, Wii, and 3DS are experimental. These systems are listed in the default config because standalone Tico cores can produce playable results, but they are not bundled with NXStation. You must download the core .nro files yourself, place them in sdmc:/switch/NXStation/cores/, then point each system to the correct core in Settings → Core Paths. See Custom Standalone Cores for download links and setup steps.

ScreenScraper Setup

  1. Create a free account at screenscraper.fr.
  2. In NXStation: Settings → enter your website username and password.
  3. Or edit sdmc:/switch/NXStation/settings/user_screenscraper.json directly: 
    {
  "ssid": "your_username",
  "sspassword": "your_password"
}
  4. Open a game list, press Y, choose scrape options, and run a single-game or batch scrape.

Developer API keys are built into the app — you only need your personal ScreenScraper login.

Adding Your Own Box Art & Videos

Files are matched by the ROM filename stem (name without extension). Example ROM: Chrono Trigger.sfc → stem Chrono Trigger.

ES-DE folder layout (recommended — auto-discovered):

  • Box art: sdmc:/roms/{systemId}/images/{stem}-image.jpg
  • Thumbnail: sdmc:/roms/{systemId}/images/{stem}-thumb.jpg
  • Video: sdmc:/roms/{systemId}/videos/{stem}-video.mp4

Supported image extensions: .jpg, .jpeg, .png, .webp

Supported video extensions: .mp4, .webm, .mkv

Using gamelist.xml for custom paths or names:

If your files use different names or folders, add entries to sdmc:/roms/{systemId}/gamelist.xml:

<game>
  <path>./Chrono Trigger.sfc</path>
  <name>Chrono Trigger</name>
  <image>./images/my-custom-box.jpg</image>
  <thumbnail>./images/my-custom-thumb.jpg</thumbnail>
  <video>./videos/my-preview.mp4</video>
</game>

After adding files, run Rescan Libraries in Settings or restart NXStation.

Video Preview Recommendations

  • Use H.264 in an .mp4 container for best compatibility.
  • Scale videos to max 480×320 before copying to the SD card — NXStation decodes at this size to avoid memory issues.
  • Shorter clips (10–30 seconds) load faster in the game list preview pane.

Game Manuals (ScreenScraper PDF)

Manual scraping is off by default. When enabled, NXStation downloads the ScreenScraper manual as a PDF and saves it to sdmc:/roms/{systemId}/manuals/{stem}-manual.pdf.

  1. Highlight a game and press Y → Menu → Scrape.
  2. Turn Manual On in the scrape toggles (along with box art, thumbnail, video if desired).
  3. Run the scrape. On success, the PDF is stored next to your ROM collection.
  4. To read it: press Y → Menu → Show Metadata → tap Manual (shown only when a PDF is present).

You can also copy a PDF manually to manuals/{stem}-manual.pdf or reference it in gamelist.xml with a <manual> tag, then rescan libraries.

The manual viewer renders the PDF directly (no low-quality JPEG conversion). Use Cover + Spread mode for a book-like layout: page 1 alone, then two-page spreads. See the controls table in Section 2.

Enabling RetroArch Logging

NXStation reads RetroArch runtime logs to calculate playtime stats. Enable logging once in RetroArch:

  1. Open RetroArch (from NXStation Settings or your forwarder).
  2. Go to Settings → Saving.
  3. Turn on Save runtime log (and keep logs enabled).
  4. Play games through NXStation so sessions are recorded under sdmc:/retroarch/playlists/logs/.

Opening Analytics in NXStation

From the main system carousel, press Y → choose:

  • Playtime Analytics — session style, time-of-day heatmaps, backlog “dust” scores, and play habits.
  • Personality Metrics — gamer tags, nostalgia breakdown, and time-warp stats derived from your RetroArch history.

Press B to close the analytics dialog. Data stays on your SD card; nothing is sent to a server.

RetroArch logging only. Playtime Analytics and Personality Metrics read RetroArch runtime logs (playlists/logs/*.lrtl). Standalone cores such as tico-dolphin and tico-azahar do not write these logs — sessions launched through those cores will not appear in analytics until you use a RetroArch libretro core that supports runtime logging.

Per-system core overrides

Settings → Core Paths lets you pick a different RetroArch or standalone .nro core per system. Overrides are saved to settings/user_cores.json. The master system list still lives in roms_config.json.

Empty game list?

  • Confirm ROMs are in sdmc:/roms/{systemId}/ with a matching folder name from roms_config.json.
  • Run Rescan Libraries in Settings.
  • If Hide Empty Systems is on, systems with zero ROMs won’t appear until you add at least one game.

Favorites & Last Played

  • Press X on a game to favorite it. Favorites sort to the top of each system list.
  • The Last Played virtual system shows your most recently launched games across all systems.
  • Favorites are stored in settings/user_favorites.json; last played in settings/user_last_played.json.

More help

See also the homepage FAQ or open Settings → Help — Data Folders inside the app for path reference.

NXStation ships with RetroArch libretro cores for most systems. GameCube, Wii, and 3DS are different: the best results today come from standalone Tico cores maintained by the community. These are separate .nro homebrew apps — you download them yourself and point NXStation at the file.

Experimental — for tinkerers. Custom standalone core support is experimental. NXStation only launches the core and passes your ROM; everything after that — stability, controls, how exit works — depends on the core maintainer, not NXStation. You may hit crashes, freezes, or end up back on the Switch home menu instead of NXStation. This path is for play testers and tinkerers who are willing to go the extra mile to download cores, tune settings, and work through rough edges.

Install on SD card

  1. Create sdmc:/switch/NXStation/cores/ if it does not exist.
  2. Copy the downloaded files, for example:
    • tico-dolphin.nro
    • tico-azahar.nro
  3. Keep filenames simple — you will browse to the exact path in Settings.
sdmc:/switch/NXStation/cores/
├── tico-dolphin.nro
└── tico-azahar.nro

Set core path in NXStation

  1. Open Settings (press + on the main carousel).
  2. Go to Core Paths.
  3. Select the system (gc, wii, or 3ds).
  4. Browse to sdmc:/switch/NXStation/cores/ and pick the matching .nro.
  5. Launch a game from that system’s list — NXStation forwards the ROM to the standalone core.

Overrides are saved in sdmc:/switch/NXStation/settings/user_cores.json. The default roms_config.json may still list RetroArch paths until you override them per system.

Analytics: Tico standalone cores do not write RetroArch runtime logs. Play sessions through them are not counted in Playtime Analytics — see Section 4.

Theme structure

Each theme is a folder with a theme.xml file:

sdmc:/switch/NXStation/data/theme/MyTheme/
├── theme.xml          (required — color definitions)
├── placeholder.jpg    (optional — system carousel fallback)
├── placeholder_box.png (optional — missing box art)
└── backgrounds/
    └── snes.jpg       (optional — per-system wallpaper)

Colors use #RRGGBB or #RRGGBBAA hex values. Example entries:

See the bundled Vampire theme for a complete reference with every key defined.

Install a custom theme

  1. Copy your theme folder to sdmc:/switch/NXStation/data/theme/YourThemeName/.
  2. Ensure theme.xml is inside that folder.
  3. In NXStation: Settings → Theme → select your theme.
