Borealis
--------

NXStation's user interface is built with Borealis, a controller- and
TV-oriented UI library for Nintendo Switch and other platforms.

  Name:     Borealis
  Authors:  Nathan "natinusala" Saliot and contributors
  Fork:     https://github.com/xfangfang/borealis
  Path:     library/borealis/ (git submodule)
  Original: https://github.com/natinusala/borealis
  License:  Apache License 2.0
  Text:      See library/borealis/LICENSE

Borealis bundles additional libraries (including nanovg, Yoga Layout, fmt,
GLFW, SDL, tweeny, libromfs, and others). Each retains its own license;
see library/borealis/library/lib/extern/ and related paths in that tree.
